# ORQUESTBA — Design system

See DESIGN_SPEC.md at the repo root for full detail. Executable summary:

- Color: navy #0E1C2F / copper #B8692A, no gradients, copper as a single accent per view.
- Typography: Space Grotesk (display), IBM Plex Sans (body), IBM Plex Mono (labels/figures). Never serif.
- Buttons: border-radius 6px, never a full pill.
- Bullets: 6px copper square, never an em-dash "—".
- 3–4 column grids: break the symmetry in at least one case per page, don't repeat the same card pattern in every section.
- Numbering (01/02/03): only if the sequence is real (e.g. "El Camino"). If decorative, remove it.
- Before marking a section done, run the checklist in section 7 of DESIGN_SPEC.md.
